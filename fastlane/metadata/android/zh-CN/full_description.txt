一念通流是一款开源的原生 Android AI 客户端，采用 BYOK（用户自备 API Key）模式：由你选择模型与工具服务、提供相应凭据，并直接连接服务端点。项目不提供账号、托管模型后端或云同步服务。

主要功能：

* 支持 OpenAI Chat Completions、OpenAI Responses 和 Anthropic Messages 兼容接口
* 支持流式对话、思考与工具过程、重试、分支、上下文清理和多会话并发生成
* 支持图片、相机、PDF、Word、Excel、文本和源码附件
* 提供收藏、Markdown 笔记、智能体和本地索引的知识库
* 提供可选的联网搜索、网页读取和文本转语音工具
* 支持中英文、深浅色主题，以及手机和平板响应式布局

数据与网络边界

会话和工作区数据主要保存在 Android 应用沙箱中。API Key 使用 Android Keystore 支持的加密存储保护；Room 数据库和私有文件没有额外的应用层全库加密。

当你主动使用网络功能时，相关提示词、附件、URL、搜索词或回复文本会直接发送到你选择的模型或工具服务。API Key 会发送到对应端点进行认证。请只配置你信任且有权使用的服务和 HTTPS 地址。

可选的非自由网络服务

应用可连接用户选择的模型供应商，也可选择使用 Exa 联网搜索、公开 InfoFlow 服务读取网页，以及 Xiaomi MiMo 生成语音。这些服务不是随应用打包的软件依赖；其服务器、条款、隐私处理、额度、价格和可用性由各自运营者控制，并可能属于专有服务。因此 F-Droid 会为本应用标注 NonFreeNet 反特征；这些集成功能均为可选。

切换分发渠道

F-Droid 构建与 GitHub Release APK 使用不同的签名证书，不能相互覆盖升级。切换渠道必须先卸载当前应用，而卸载会删除应用私有目录中的本地数据。

使用密码加密的 .tfcfg 导出文件只包含配置与凭据，并不是完整的工作区备份。它不包含会话、消息、附件、收藏、笔记、知识文件、头像或全部界面偏好。应用当前不支持完整导出工作区；卸载或切换渠道前，请先确认哪些内容可以保留。
