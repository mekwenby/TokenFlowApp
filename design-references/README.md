# Android 设计参考图

本目录保存 2026-08-16 形成的 UI 探索图，用于讨论布局、密度、配色和功能分组，不是当前 App 的像素级规范，也不是实现状态的权威来源。

## 来源、作者与许可

- 这些图片是在项目维护者 `mek` 指导和筛选下形成的 AI 辅助 UI 概念探索，并由维护者导入本仓库。
- 本目录未保存可核验的具体生成服务、模型或逐图提示词记录，因此不对这些信息作推定；文件名和日期只描述仓库中可确认的分组与形成时间。
- 项目维护者对其拥有授权权利的构图、整理和视觉资产按照仓库根目录的 [Apache License 2.0](../LICENSE) 提供。如单个文件另有明确的第三方版权或许可标注，以该标注为准；Apache-2.0 不授予项目名称或相关商标的使用权。

本目录仅用于设计讨论，不是应用运行时依赖，也不会打包进 APK。源码分发或 F-Droid 构建可以删除本目录，不影响应用功能或构建结果。

## 目录

- `calm-jade-pages-20260816/`：围绕青玉主视觉整理的页面级参考，包括会话管理、空状态、Chat 设置、供应商、搜索、系统提示词、配置和宽屏布局。
- `ui-explorations-20260816/`：不同颜色、信息密度和工作区布局的探索方案。

## 使用规则

- 判断现有行为时以 Compose 源码、资源文案和运行截图为准。
- 参考图中的按钮、字段、颜色和流程可能尚未实现、已经调整或仅用于比较方案。
- 新设计若明确采纳某张参考图，应在对应需求或变更说明中记录文件名和偏差，不直接把整批图片视为验收基线。
- 不在本目录存放签名材料、设备截图中的敏感 API Key、真实对话或用户数据。

当前功能边界见 [`../docs/FEATURES.md`](../docs/FEATURES.md)，响应式布局阈值见 [`../docs/ARCHITECTURE.md`](../docs/ARCHITECTURE.md)。
