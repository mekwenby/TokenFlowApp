# Android 功能与限制

本文记录版本 `2.6.0`（`versionCode 22`）的实现能力。具体交互文案以 App 资源为准，数值上限以源码常量为准。

## 模型与供应商

- 支持 OpenAI Chat Completions、OpenAI Responses 和 Anthropic Messages 兼容接口。
- 可测试供应商连接、读取远端模型列表或手动添加模型。
- Base URL 必须是干净的 HTTPS API 根地址，不允许 userinfo、query 或 fragment。
- 模型最大输出长度默认 `16,384` Token，可配置范围为 `1..500,000`。
- 首次启动没有模型时，可新建供应商或导入 `.tfcfg`；归档未指定默认模型时采用其中首个模型。

## 对话

- 多轮流式回复、思考/工具过程、停止、重试最后回复和自动标题。
- 每个会话有独立生成任务，可在切换会话后继续运行。
- 会话支持搜索、重命名、分支、置顶、归档、恢复、多选和批量删除。
- 分支复制目标 Assistant 回复之前的消息和附件，并使用新 UUID。
- “清空上下文”保留历史消息并显示分割线，但后续请求不再携带分割线之前的上下文。
- Token 行显示总量、输入、输出和供应商报告时的缓存命中率，例如 `2.6K↑2.5K↓100 · 缓存 80%`。
- 生成期间隐藏或稳定过程/操作控件，避免流式更新造成按钮抖动；完成后 Token 与过程入口左右对齐显示。

## 全局消息搜索

- 导航中的“搜索消息”独立于会话标题筛选，检索所有会话的用户和助手正文，包含归档会话。
- 中文和英文大小写忽略的字面子串查询；不解释 `%`、`_` 或查询运算符。输入最多 200 字符，防抖 300 ms，按消息时间和 ID 倒序每页 50 条。
- 搜索结果只读取会话身份、角色、时间和最多 400 字符的命中片段，不把全部聊天载入内存。结果高亮关键词，点击后加载会话、定位并短暂突出消息。
- 附件正文、思考、工具日志和生成中的消息不参与搜索；中断和失败消息已经持久化的正文可以检索。归档会话无需恢复即可查看。

## 上下文管理

- 会话“更多”菜单提供完整历史、仅最近 N 轮、历史摘要三种模式；N 默认为 6，范围 1–50。一轮从用户消息开始，包含其后的已完成助手回复。
- 可预览系统提示词、携带的消息、附件提取文本和实际工具定义，查看近似输入 Token 和输出预留。图片根据分辨率估算，不按 base64 字符长度计算；估算不是账单 usage，也不保证与各供应商 tokenizer 一致。
- 模型可填写上下文容量；默认未知，不自动猜测。容量必须大于最大输出 Token，未配置时不显示百分比，也不能压缩。
- 自动压缩默认关闭，按会话开启；输入达到“容量减最大输出”的 80% 时使用当前模型生成滚动摘要。优先保留最近 N 轮，必要时减少保留轮数，但不压缩当前提问。
- 摘要关闭思考和工具，输出最多 2,048 Token，并服从模型输出上限；历史过长时分批处理。当前问题本身超出预算时停止，要求减少附件或调整容量。
- 手动摘要先预览、编辑并确认，自动摘要直接生效。过程展示压缩状态和独立摘要 usage，不并入回复账单 Token 行。原始历史和附件仍保留，可以恢复完整上下文。
- 摘要保存来源消息与边界校验；清空上下文后失效。分支仅复制在分支范围内有效的摘要并重映射消息身份。
- 压缩、取消或预处理失败不会提交新用户消息或摘要；已提交的回复占位与用户消息一起落盘，允许中断后重试。每次工具循环后续请求检查容量，超限时保留已有结果，不裁剪工具调用链。

## Android 分享与草稿

- 支持系统 `SEND`、`SEND_MULTIPLE` 的文字、网址及已有支持的图片/文档类型；选择新会话、已有会话或智能体后导入草稿。
- “总结、翻译、提问”快捷操作只添加可编辑的要求；翻译目标默认当前应用语言，发送始终需要用户操作。
- 目标已有草稿时追加文字和附件，超限则保留原草稿与分享预览，允许移除文件后继续。正在生成的会话不可作为导入目标。
- 分享附件立即复制到私有草稿目录，临时外部 URI 后续失效不会影响副本；按实际读取字节数执行现有 5 项、单图 5 MiB、单文档 2 MiB、合计 20 MiB 限制。
- 文字与附件草稿按会话保留，支持切换、旋转和进程恢复。同一分享事件仅导入一次，新事件即使内容相同也可继续导入。
- 移除、取消和发送成功后清理分享副本；不再被草稿引用的副本闲置 24 小时后清理。分享草稿不属于完整备份。

## Markdown 与来源

- Assistant 和笔记阅读模式支持 CommonMark、GFM 表格、自动链接、安全内联 HTML、代码复制和常见语言语法高亮。
- HTTP/HTTPS 来源以链接样式显示，点击交由系统浏览器处理。
- 本地知识引用使用经 metadata 验证的 `[[KB:<chunkId>]]` 标记，显示为文档名和 1 基片段编号，点击在 App 内预览。
- 代码块、未知标记和伪造 chunk ID 不会变成可点击本地来源。

## 附件与视觉

每条消息最多 5 个附件：

| 类型 | 单项上限 | 处理方式 |
| --- | --- | --- |
| 图片 | 5 MiB | 直接视觉输入或由兜底视觉模型生成描述 |
| 文档 | 2 MiB | 在设备上提取文本后进入模型上下文 |
| 总计 | 20 MiB | 超限时发送前拒绝 |

文档提取覆盖常见纯文本/源码、PDF、Word 和 Excel。单文档最多提取 100,000 字符，每条消息的文档文本合计最多 200,000 字符，PDF 最多读取前 100 页。

相机入口使用外部相机和 `FileProvider`，不申请 CAMERA 或存储权限。照片会校正 EXIF 方向，最长边限制为 4096 px，并以 JPEG 质量 75 写入私有草稿；草稿最长保留 24 小时。

模型支持视觉时直接发送图片。当前模型不支持时，可由已通过视觉检测的全局兜底模型先生成描述，再交给原会话模型。

## 本地工作区

### 收藏

- 收藏以紧凑单行会话标题显示，搜索仍可匹配标题和隐藏正文。
- 点击打开来源会话，支持取消收藏、长按选择和批量删除。
- 删除来源会话时收藏随 Room 外键级联删除，UI 同步移除，避免打开陈旧会话。

### 笔记

- Markdown 阅读/编辑、搜索、多选和批量删除。
- 笔记列表每次可导入一个 `.md` 文件；扩展名大小写不敏感，文件必须是严格 UTF-8 且不超过 2 MiB。
- 导入时以去掉末尾 `.md` 的文件名作为标题，正文仅移除可选的 UTF-8 BOM，其余空格和换行保持不变。
- 阅读页可将当前单篇笔记的正文原样导出为 `.md`，保存位置由系统文档选择器决定。
- 同一来源 Assistant 消息最多创建一条笔记。
- 可选择模型重写正文并生成标题；自定义提示词只进入正文重写请求，不持久化，也不进入标题请求。
- 笔记正文最大可用于重写的输入长度为 120,000 字符。
- 笔记可作为会话附件导入。
- 保存到知识库前显示快照确认。同一笔记最多保留一个 `ready/indexing` 知识副本；删除知识副本后可重新保存。
- 知识副本通过非外键 `sourceNoteId` 关联。后续编辑或删除笔记不会更改已经导入的知识内容。

### 智能体

智能体可保存模型、系统提示词、思考强度、最大工具调用数，以及联网搜索、URL 读取和本地知识库开关。

### 知识库

- 支持 TXT、Markdown、JSON、CSV 和 PDF，单文件最大 20 MiB，PDF 最大 500 页，提取文本最大 2,000,000 字符。
- 原文件复制到 App 私有目录，解析后分块并写入 Room FTS；搜索兼顾拉丁 token 与中文 bigram。
- 开启知识库后，发送前自动用本次用户正文检索，手动片段优先，自动结果补足到 5 个。
- 注入正文最多 20,000 字符，视为不可信资料，不允许其中内容覆盖系统指令。
- 本地资料不足且工具额度可用时，模型可调用 `search_knowledge` 改写关键词再次检索，再决定是否联网。
- 自动、手动和工具检索均记录在“过程”中；过程只列文档名和片段位置，不展示整段正文。

## 离线计算与单位换算

- 模型可调用 `calculate` 执行常用科学计算，或调用 `convert_units` 换算长度、质量、温度、面积、体积、速度、时间、压力、能量、功率、角度和数据容量。
- 两个工具完全在设备内执行，不使用网络或第三方工具服务；它们始终可供模型使用并计入现有工具调用额度。最大工具调用数设为 `0` 时，所有工具都会禁用并且不会发送给模型。
- 计算器支持四则运算、幂、括号、科学记数法、常用聚合/取整/对数/三角函数，以及 `PI`、`E`。三角函数使用弧度；可用 `RAD(deg)` 和 `DEG(rad)` 转换角度。
- 百分比使用 `PERCENT(13)` 或 `13/100`，取模使用 `MOD(a,b)`；不接受有歧义的 `%`，也不支持变量、脚本、字符串、布尔、日期或随机数表达式。
- 单位换算只允许同一维度，并使用严格区分大小写的规范单位标识符。美制与英制体积显式区分，例如 `gal_us` 和 `gal_imp`；`B` 表示字节、`bit` 表示位，十进制数据单位与 `KiB/MiB/GiB/TiB` 等 IEC 单位分别计算。
- 时间中的 `d` 固定为 24 小时、`wk` 固定为 7 天；`cal/kcal` 使用热化学卡，`hp` 使用机械马力。温度换算会拒绝低于绝对零的数值。

## 联网工具

- Exa Key 用于网页搜索，默认返回最多 5 个结果，工具输出最多 20,000 字符。
- URL 读取可选择内置读取器或公开 InfoFlow 接口。
- URL Reader 只允许公共 HTTPS/443；内置读取器限制 5 次重定向和 2 MiB 下载，并在每次重定向后重新执行地址校验。
- InfoFlow 失败时可回退内置读取器。InfoFlow 兼容 Key 不再应用或导出。

## Infinite Cloud

- App 通过 SSH 私钥直接连接 Linux；首次连接必须确认 SHA-256 主机指纹，指纹变化会阻断连接。不支持密码认证、DSA 或 RSA/SHA-1。
- 可即时运行 Shell、Python 3 和 Node.js，浏览/编辑/上传/下载远程文件；只有用户明确要求创建任务、后台运行或异步执行时，模型才获得后台任务工具。即时执行不进入任务列表，显式后台任务可在断线后继续运行。已结束任务支持多选并批量删除本地历史，远端任务目录和文件不会随之删除。
- 轻量 Python helper 安装在 `~/.tokenflow/infinite-cloud/`，不监听网络端口。即时执行使用自动清理的临时目录，完整状态与日志只为显式后台任务持久化。
- 每个会话和智能体可选择一台服务器。启用后，模型无需逐次确认即可使用该 Unix 账号允许的全部操作；本条消息全部附件会在模型生成前自动上传。
- 支持远程 stdio 与 Streamable HTTP MCP；同一服务器下所有 MCP tools 会在生成开始时动态发现，并在本次生成的 `ToolSession` 内复用连接。MCP secrets 只加密保存在设备上；文本和结构化结果进入工具消息，image/audio/blob 保存为 Assistant 可下载附件而不把 base64 塞入模型上下文。
- 默认每服务器并发 2、任务时限 60 分钟，可配置并发 `1..4`、时限 1 分钟至 24 小时；即时工具调用最多等待 120 秒，超时不会自动转为后台任务。

## 语音

- 配置 MiMo Key 和音色后，可用 `mimo-v2.5-tts` 为已完成 Assistant 回复生成 WAV。
- 音频只放在 `cacheDir/mimo_tts`，不写入 Room；缓存丢失后可重新生成。
- Media3 ExoPlayer 管理播放和 Audio Focus。
- 自动播放事件仅由发起生成的当前 Chat 页面消费一次；离开再返回不会重放旧事件。

## 外观与可访问性

- 简体中文/英文、系统深浅色和六套主题，其中墨夜纯黑使用 AMOLED 纯黑背景。
- 英文应用名为 `TokenFlow`，简体中文应用名为“一念通流”；About 页可离线阅读双语用户协议和完整第三方许可证声明。
- 全局设置可配置所有模型共用的助手昵称，默认“一念无限”；每条新回复同时记录生成时昵称和实际模型 ID，后续改名不会重写已有回复的署名。
- 全局和会话头像按正方形中心裁剪为 384x384 PNG。
- Chat 可调整字体、字间距和行间距。
- 手机抽屉、平板常驻导航和超宽屏三栏布局；短高度或大字体下导航入口使用独立滚动区域，阈值见 [架构说明](ARCHITECTURE.md)。

## 配置导入导出

- `.tfcfg` 是密码加密归档，包含供应商/模型（含可选上下文容量）/凭据、默认模型、视觉兜底、Exa/MiMo、全局助手昵称、全局提示词、URL Reader 和智能体。
- 不包含会话、消息、附件、收藏、笔记、知识文件、头像或界面偏好。
- 笔记 `.md` 只能逐篇导入或导出，不会加入 `.tfcfg`，也不能替代完整数据备份。
- 导入先生成新增、更新和冲突摘要，确认后按稳定 UUID 合并。

## 编辑提问、后台生成和知识范围

- 用户消息中的编辑按钮打开可修改的提问；确认后创建新分支，复制编辑点之前的有效历史与附件，保留原会话及后续消息。编辑分支重新检索知识并沿用上下文策略；失败后可重试，不重复插入提问。
- 生成由应用级 coordinator 与 dataSync 前台服务托管，Activity 重建和切换应用不取消已接管任务。通知提供停止操作，后台完成/失败提醒可打开对应会话；前台完成时不额外提醒。Android 13 及以上首次生成请求通知权限。系统强制停止或杀死进程时不会自动重发模型请求，已生成内容仍保存在本地，可手动重试。
- 会话菜单和知识库页可选择全部文档或指定已就绪文档；指定范围为空表示不检索文档。范围应用于手动搜索、自动检索、指定片段与模型 search_knowledge 工具。既有消息和摘要不删除，正文仍采用 Room FTS 关键词检索。
