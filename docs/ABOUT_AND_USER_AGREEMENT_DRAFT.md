## 一、关于页面文案

### 功能介绍

一念通流是一款由用户自备 API Key 的 Android AI 客户端，支持 OpenAI Chat Completions、OpenAI Responses 和 Anthropic Messages 兼容接口，可直连用户配置的模型服务。

- **多模型直连**：自由配置供应商、模型和最大输出长度，模型请求发送至用户设置的服务地址。
- **完整对话**：支持流式回复、思考与工具过程、停止与重试、自动标题、消息分支、置顶、归档、搜索、清空上下文，以及图片、文档和笔记附件；可查看输入与输出 Token、缓存命中率等调用信息。
- **本地工作区**：提供收藏、Markdown 笔记、智能体和本地知识库。笔记可调用指定模型重新生成标题并总结正文，也可导入知识库用于本地检索。
- **可选扩展**：可配置 Exa 联网搜索、网页正文读取、视觉模型兜底和 Xiaomi MiMo 语音生成；支持系统提示词、头像、字体与字间距设置，以及加密的配置导入导出。

### 服务 Key 申请

以上服务由相应第三方提供。申请、计费、额度、数据处理和可用性以第三方届时公布的规则为准。
