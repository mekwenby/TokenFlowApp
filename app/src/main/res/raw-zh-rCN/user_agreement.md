## 5. 本地存储与数据传输

1. 对话、收藏、笔记、智能体、知识文件及相关设置主要保存在本应用的私有存储空间。本应用当前不提供聊天数据的云端同步或恢复服务。
2. 使用相应功能时，相关数据可能按下列方式离开设备：
   - API Key 会作为认证信息发送到您配置的服务地址。自定义地址的运营者将收到相应凭据和请求内容。
   - 对话历史、系统提示词、附件内容或描述及检索到的知识片段可能发送给已配置的模型供应商。
   - 笔记正文可能发送给您选择的模型，用于生成标题或重写正文。
   - 使用联网搜索时，搜索词及参数会发送给 Exa。
   - URL 及相关请求信息可能发送给 InfoFlow、目标网站，或由本应用直接请求目标网站。
   - 搜索结果和提取的网页正文可能作为工具结果继续发送给已配置的模型。
   - 您选择生成语音的文本及语音参数会发送给 Xiaomi MiMo。
3. 外部服务运营者可能依其自身政策记录、处理、保存或跨境传输收到的数据。启用服务前请查阅相应政策。
4. 语音文件等临时结果可能保存在应用缓存中，并由 Android 或本应用清理。导出的加密配置文件位于私有应用存储之外，由您自行保管。
5. 删除本地内容或卸载本应用只影响本应用能够控制的副本，不会删除外部服务保存的副本或您导出的文件。
